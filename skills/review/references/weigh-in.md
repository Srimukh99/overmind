# weigh-in

For each comment:

1. Restate it in one line to confirm you understand it.
2. Check it against the code, the tests and the requirements.
3. Decide:
   - **Correct**: fix it, with a test where behaviour changes.
   - **Unclear**: ask a specific question before touching code.
   - **Wrong**: reply with evidence (a test, a doc, a line reference). Respectful, not defensive.
   - **Out of scope**: log it as a follow-up.
4. Apply changes one at a time and re-run tests after each.

Finish with a short table: comment, decision, what changed.
