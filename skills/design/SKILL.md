# design

Nothing is built until the user approves a design. Read only the part you need.

| Situation | Read |
| --- | --- |
| Asked to build a feature, add behaviour, or change how something works, before writing any code. Turns a fuzzy ask into a short design the user approves. | `references/shape.md` |
| A design is approved or a multi-step change needs a plan before coding. Breaks the work into small tasks with exact files, a test to write first, and a command that proves each task works. | `references/blueprint.md` |

Order: `references/shape.md`, then `references/blueprint.md` once the design is approved. Skip shape when a design already exists.
